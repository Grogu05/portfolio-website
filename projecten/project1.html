Zelfgehoste Minecraft-server

Een Minecraft-server zelf hosten om hostingkosten te vermijden — op vraag van mijn kleine broer.

Hobby Port forwarding Networking 2025

Doel

Een 24/7 beschikbare Minecraft-server opzetten voor vrienden en familie, zowel thuis als extern, zonder afhankelijk te zijn van commerciële hostingdiensten.

Aanpak

  1. Een geschikte machine kiezen om de server op te draaien.
  2. Minecraft-serversoftware installeren en configureren.
  3. Netwerk instellen: correct IP-adres en poorten (port forwarding/NAT).
  4. Testen vanop het lokale netwerk en van buitenaf.

Resultaat

De server draait stabiel op een compacte office-pc met laag stroomverbruik. Voor de software koos ik de gratis Java-server van Mojang. De initiële installatie was eenvoudig; de uitdaging zat in externe bereikbaarheid: poorten forwarden op de router en testen van buitenaf. Omdat mijn publieke IP-adres dynamisch is, heb ik DuckDNS toegevoegd. Daardoor verwijst een vaste domeinnaam automatisch naar mijn actuele IP-adres en kunnen vrienden altijd verbinden zonder dat ik mijn IP hoef te delen.

Technologie

  • Port forwarding / NAT
  • Networking (LAN/WAN)
  • IPv4 + Dynamic DNS (DuckDNS)
